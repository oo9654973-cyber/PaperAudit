# Reviewed community template links

`approved-catalog.json` is the **publicly reviewed directory**, NOT the pending submissions inbox.

Each entry requires at least:

```json
{
  "status": "approved",
  "name": "Example Journal (illustration only)",
  "discipline": "optics",
  "language": "en",
  "url": "https://publisher.example.org/instructions",
  "desc": "Official author instructions; submission stage checked.",
  "source": "Official journal website",
  "reviewedAt": "YYYY-MM-DD"
}
```

Review checklist: confirm source URL is an official publisher/journal entry, current applicability and manuscript type, license/redistribution scope, and whether the submission is a template versus a guide. Reject personal manuscripts and unauthorised copies. Link to authoritative templates instead of mirroring the actual file by default. Do not claim a community-provided rule is officially verified until it has been checked against an official source. Maintain changes via PR review.
